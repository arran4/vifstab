# vifstab(8)

## NAME
vifstab - Edit fstab files with linting and versioning

## SYNOPSIS
vifstab [--backup-dir=<value>] [--file=<value>] [--generate-manpage] [--help|-h]

## DESCRIPTION
**Usage**:
vifstab [OPTIONS]

## OPTIONS
**--backup-dir**="": Directory to store RCS backups (defaults to a sensible location based on the file being edited and the user running the command)

**--file**="": File to edit (default: "/etc/fstab")

**--generate-manpage**: Generate man page for vifstab to vifstab.1

**--help**, **-h**: show help
